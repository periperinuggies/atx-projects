Section 01 — Landscape

The Two Ecosystems

Kali Linux is a curated, battle-hardened distro with 600+ tools across every pentesting discipline. Flipper Zero is purpose-built portable hardware with radio, NFC, RFID, IR, BLE, and GPIO. They're complementary — not competing.

🐉
Kali Linux
Curated pentesting OS
Network ReconWeb AppExploitationPassword CrackingWirelessPost-exploit

Six major categories. Tools like Nmap, Metasploit, Aircrack-ng, Wireshark, Burp Suite, and Hashcat are industry-standard. Maintained by Offensive Security with a strict vetting process — if it's in Kali, it's trusted.

🐬
Flipper Zero
Portable hardware multi-tool
Sub-GHz RFNFC / RFIDInfraredBLEBadUSBiButton

STM32-based portable with radios Kali can't touch without external hardware. Native sub-GHz at 300–928 MHz, 125kHz RFID, 13.56MHz NFC, IR blaster/receiver, and Bluetooth — in a device that fits in a pocket.

📡
WiFi Dev Board
ESP32 expansion module
2.4GHz WiFiMarauderNetwork Scan

The ESP32 WiFi board unlocks Marauder firmware, enabling deauth attacks, PMKID capture, evil portal, and basic WiFi scanning. Closes the biggest gap between Flipper and a Kali laptop for wireless attacks.

⚠️
The Gap
Where opportunity lives
No Passive Recon UINo Protocol AnalysisNo BT Fingerprint

Kali's highest-value tools — Nmap, Wireshark, Kismet, BlueHydra — have no Flipper equivalent. The hardware could theoretically support many of these via modules, but the software layer doesn't exist yet.

Section 02 — Firmware

Custom Firmware Landscape

The firmware you run determines what's possible. Active options in 2025:

Official STABLE

Stock firmware from Flipper Devices. Stable, safe, limited to regional frequency restrictions. Good starting point, mandatory for understanding baseline capabilities.

Full app store access (lab.flipper.net)
Conservative sub-GHz frequency limits
No BLE spam, limited protocol support
Unleashed ACTIVE

The pragmatist's choice. Based on Official firmware with regional restrictions removed, rolling code support, and functional improvements with minimal bloat.

Full sub-GHz frequency range unlocked
Rolling code support (KeeLoq, etc.)
BLE spam included
Subdriving (GPS coordinate logging)
Momentum ACTIVE

Direct continuation of Xtreme (which died Nov 2024). Feature-rich, highly customisable UI, same dev team. Best balance of features and stability for power users.

All Unleashed features plus UI customisation
Advanced security (lock on boot, bad PIN wipe)
Bad BT (HID injection via Bluetooth)
Asset packs, management app
RogueMaster ACTIVE

Kitchen-sink approach — every feature from every firmware, plus extra apps and animations bundled in. Largest app bundle but least stable. Best for experimentation.

Largest bundled app collection
Unleashed + Xtreme features merged
Most animations and cosmetics
Trade-off: stability vs breadth

Recommendation for pentesting

Momentum on the device itself (stable, full feature set), with Marauder on the WiFi dev board for wireless attacks. If you're building and testing your own apps, Official firmware gives the cleanest base — no unexpected interactions with CFW patches. RogueMaster is useful for evaluating what's already been built before reinventing anything.

Section 04 — Opportunities

9 Apps Worth Building

Ranked by community demand, technical feasibility, and gap size. Priority 1 apps have the highest combination of all three — most popular, most achievable, biggest gap in the current ecosystem.

🗺️
⬆ PRIORITY 1
FlipMap
Passive LAN host discovery via ESP32

A clean Nmap-lite for the Flipper. Uses the WiFi dev board to perform ARP sweeps and passive traffic sniffing on connected networks. Displays discovered hosts, open ports, and device fingerprints on the Flipper's screen. Export to SD for later analysis. This is the single most-requested capability that doesn't cleanly exist yet — Marauder can deauth but has no host discovery UI.

ESP32 Required WiFi C / FAP Serial Protocol
Kali Equiv nmap · arp-scan · masscan · netdiscover
Community Demand97%
📶
⬆ PRIORITY 1
BLEprint
BLE passive OSINT scanner & fingerprinter

Passively scans BLE advertisements and fingerprints nearby devices by manufacturer data, UUID, and advertising patterns. Classifies devices (Apple Watch, AirPods, Samsung Galaxy, Tile tracker, medical device, smart lock) and tracks RSSI over time. Useful for OSINT walkthroughs and physical security assessments. BlueHydra does this on Kali; nothing comparable exists for Flipper.

Native BLE No Module Needed C / FAP Offline DB
Kali Equiv btlejack · bluehydra · bettercap (ble.recon)
Community Demand94%
📻
▲ PRIORITY 2
RFClassify
Intelligent sub-GHz signal classification

Extends the built-in spectrum analyser with protocol identification. Captured signals are analysed against a known-protocol database — OOK, FSK, ASK, Z-Wave, LoRa, 433MHz garage systems, car key fobs — and labelled with confidence percentage, modulation type, and known vulnerabilities. Currently the Flipper shows a signal exists; this tells you what it is and what you can do with it.

Sub-GHz Native No Module Needed Protocol DB SD Export
Kali Equiv gqrx · gnuradio · rtl_433 · universal radio hacker
Community Demand88%
🕸️
▲ PRIORITY 2
PortalKit
Polished evil portal with credential capture UI

Marauder includes a basic evil portal, but it's raw. PortalKit adds a curated template library (WiFi reconnect, corporate login, bank auth, hotel captive portal), one-tap deployment via the Flipper UI, and a live credential log displayed on screen. Captured creds stored to SD. No laptop needed for a complete captive portal engagement.

ESP32 Required WiFi Template Engine Builds on Marauder
Kali Equiv SET · gophish · wifiphisher · evilginx
Community Demand85%
💳
◆ PRIORITY 3
CardAudit
NFC/RFID security vulnerability scanner

Goes beyond read-and-replay. Scans detected NFC/RFID cards against a CVE database of known weaknesses — Mifare Classic default keys, Mifare Ultralight without authentication, RFID cloneable sectors, EM4100 replay vulnerabilities. Returns a structured report: card type, detected vulnerabilities, exploitation risk level, and remediation notes. Useful for physical pen tests and access control audits.

Native NFC + RFID Offline CVE DB No Module Needed PDF-like Report
Kali Equiv mfoc · libnfc · mfterm · nfc-tools
Community Demand79%
🤝
◆ PRIORITY 3
HandShake
Guided WPA2 capture workflow

A clean UI wrapper around Marauder's deauth + PMKID/EAPOL handshake capture — the hardest-to-use part of the WiFi dev board workflow. Target selection with signal strength display, deauth burst with progress indicator, handshake detection with audio/visual confirmation, and one-tap save to SD in hashcat-ready .cap format. Makes this standard recon step accessible without typing commands.

ESP32 Required WiFi Marauder Backend .cap Export
Kali Equiv aircrack-ng · wifite · hcxdumptool · bettercap
Community Demand76%
⌨️
● PRIORITY 4
DuckyVault
BadUSB payload library with results capture

Curated, categorised library of audited BadUSB payloads with on-device management — browse by category (recon, persistence, credential dump, exfil), preview payload before launch, capture output from powershell/cmd over a serial channel back to Flipper screen, and save results to SD. Bridges the gap between launching a payload and actually receiving its output — currently payloads run blind.

Native BadUSB No Module Needed Payload Library Serial Capture
Kali Equiv SET · powershell-empire · covenant · ducky encoder
Community Demand70%
🎯
● PRIORITY 4
Playbook
Multi-stage attack orchestration

Chains Flipper capabilities into repeatable engagement playbooks. Define a sequence: BLE spam → wait 10s → BadUSB payload → Sub-GHz replay → IR jam. Run from SD-card .yaml files. Each step has configurable delays, success conditions, and fallback actions. Think of it as a programmable macro system for physical pen tests — no equivalent exists in the ecosystem.

All Radios YAML Playbooks SD Required High Complexity
Kali Equiv metasploit (multi/handler) · ansible-playbook for attacks
Community Demand65%

○ PRIORITY 5
FlipperRadar
Nearby Flipper Zero detector with directional RSSI

Detect other Flipper Zeros via BLE advertisement fingerprinting. Displays RSSI signal strength as a directional radar sweep on screen — walk toward the signal to find physical location. Useful for CTF scenarios and fun social discovery. Community has been requesting this for years; technically straightforward since Flippers advertise a known BLE signature.

Native BLE No Module Needed RSSI Ranging CTF / Community
Kali Equiv kismet · wireshark (BLE) · btlejack

Section 05 — Roadmap

Suggested Build Order

Sequenced for maximum impact and learning curve. Each phase builds on the last.

Phase 1 — Foundation
BLEprint — BLE Device Fingerprinter

Start here. No external module required. Pure C FAP development against Flipper's native BLE stack. Builds skills in FAP framework, UI rendering, and SD card storage. The deliverable is immediately useful and community-friendly enough to get early traction on GitHub.

Phase 2 — RF Layer
RFClassify — Signal Protocol Classifier

Still no module needed. Extends Phase 1 skills into sub-GHz. Build the protocol database in JSON on SD card — community can contribute entries via GitHub PRs. This becomes a living, crowd-sourced intelligence layer.

Phase 3 — WiFi Layer
FlipMap + HandShake — Network Recon Suite

First module-dependent apps. Requires establishing a reliable serial communication protocol with ESP32/Marauder. Build FlipMap first (simpler read-only), then HandShake (read + write). At this point you have a genuinely useful field pentesting toolkit.

Phase 4 — Physical Access
CardAudit — NFC/RFID Vulnerability Scanner

Leverages native NFC/RFID hardware. Build the CVE database from existing public research (Proxmark documentation, NFC research papers). This is the highest-value tool for physical security professionals and a clear differentiator from anything currently in the app store.

Phase 5 — Orchestration
Playbook — Attack Sequencer

The capstone. Requires all previous phases working. Design the YAML schema first, share it publicly for community feedback before writing a line of code. This is the app that makes the Flipper genuinely dangerous as a standalone engagement tool — and the one most likely to generate media attention.
